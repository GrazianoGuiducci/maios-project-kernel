# MAIOS Project Kernel 5.5.0

5.5.0 consolidates compatible practical kernel knowledge. Product sources and
their deterministic package are the result; a branch, version label or passing
build does not establish a published Release or updated installation.

## Work that changes the next capacity

The kernel can deepen, compose or form the competence pertinent to a real
movement and keep its reasons available across interruption. Formation now
carries concrete methods for situated focus, principles that change an ability,
continuing activities, source transformations and learning from observed work.
Acquisition already supplies source/means knowledge; existing owners continue
that contribution instead of multiplying faculties by name.

A useful possibility can retain its source and reason before its form or return
time is known. When it becomes pertinent, understand it in the changed present;
do not execute an old conclusion merely because it was preserved. If an actual
choice is needed among materially informed equivalents, avoiding unnecessary
irreversible loss can be a residual criterion; valid operator criteria and
real effect conditions continue. Unknown distinguishing facts are not equivalence.

## Connected work, people and effects

Coordination follows the contribution that can improve the result, the receiver's
knowledge/means, necessary context and transfer/return cost. A local next action
can coexist with complementary work; no fixed model hierarchy or delegation
requirement is introduced. Bounded contributions return to the containing work.

Continuing activities retain intent, competence knowledge, editable instructions,
actual controller and consequences. The method can change suitability, overlap
or retirement without installing a scheduler in this package.

Source transformations retain meaning, interpretation and exact-effect authority.
On interrupted work, completed, pending, failed and uncertain operations have
different continuations. Inspect the actual controller before retrying an
unknown effect; preserve still-valid authority. Human encounters can change
understanding and the method, without inventing a permanent personal profile.

## Situated knowledge and continuation

Shared artifact facts, current access and observed behavior have different
scopes. One instance does not inherit another's tools or experience from a
shared adapter label. Observation and demonstration methods follow actual
exposure, supplied help, choice and consequence; a saved body is not use.

For an evolved local kernel, compare distributed base, living local knowledge
and proposed source. Preserve useful local contributions, required references,
native consumers and reasons. Keep the original installation receipt attributable
to the installation that occurred. The [updating guide](UPDATING.md) explains
bounded selective integration without an automatic merge or receipt rewrite.

## Compatibility and version choice

The product advances from 5.1.0 to 5.5.0 as a substantial compatible evolution
of delivered methods. Family remains 3.0.0. Runtime, installer/recovery,
configuration/operating schemas and host contracts retain their compatibility.
Python >=3.11 and qualified 3.11–3.14 on Linux, Windows and macOS are unchanged.
No new generator, receiver-state database, automatic updater or scheduler is
required. An existing installation is not migrated by this source change.
See [compatibility](COMPATIBILITY.md), [version](../VERSION.md) and
[installation/recovery](INSTALLATION.md).

## Evidence and limits

A [bounded observation](USE_OBSERVATION_5.5.0.md) exercised a precursor carrying
the delivered method bodies. A receiver formed a local method from a synthetic
contact task, completed a native compact and continued with new source facts.
The supplied file adapter, assistance and unexercised paths remain explicit.
Finalization compares the fourteen candidate knowledge bodies with that precursor;
versioned source, projections and archive receive their own technical evidence.

The source qualification contract is the complete suite, active document links,
two byte-identical packages, distribution verification, committed package
agreement and the twelve OS/Python CI jobs. Exact commit, run, archive and
checksum identities belong to their external readbacks, not a self-referential
source receipt. A local pass does not assert a CI pass or publication.

One model/adapter case does not prove every host, terminal operation, managed
reentry transition, causal improvement over 5.1.0 or general assimilation.
The neutral sources remain readable without private source access or the
observation's test client. Site, Form, tags/Releases and live installations
remain separately selected effects.
