# MAIOS Self-Configuring Setup

Pacchetto pronto per configurare un nuovo progetto con il proprio assistente.
Non contiene il sorgente di RepoKernel: contiene il Project Kernel generato,
la sua meta-facolta semantica con adattatori di discovery, le facolta locali e
lo stato necessario a iniziare e riprendere il lavoro. Il contratto evolutivo
tipizzato e in `kernel/PROJECT_EVOLUTION_CONTRACT.json`.

Apri `START_HERE.md`.

Stato iniziale: configurazione da svolgere con la persona.
Target: nuova cartella di progetto, non un repository esistente.
