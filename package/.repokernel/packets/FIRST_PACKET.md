# First Packet

objective: configure this new project with the user
intent: establish a situated Project Kernel and a useful first result
boundary: project-local configuration; external effects remain separate
state_provider: packaged kernel plus current project evidence
write_owner: project user
first_safe_action: read START_HERE.md and begin the startup interview

## First Orientation

Observe the files that exist before asking questions. Return a short initial
reading of the context, propose one corrigible first result and ask only for the
information that changes the project direction.

Use `maios-setup-interviewer` while configuration is pending and
`maios-project-faculty-router` to select or compose capabilities. A new local
skill is a candidate only when an actual capability gap remains; the project
owner reviews it before it becomes an active rule.

## Reentry

After each accepted movement, update `project/CURRENT_STATE.md` and the
structured setup state so a fresh session can continue without rebuilding the
conversation.
