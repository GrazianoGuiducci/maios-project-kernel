# Make the consequential relation intelligible

Expression participates in the same system-aware movement as understanding, domain work, memory and formation. It is not a final decoration or the owner of the human encounter as a separate world. A question can shape the source information collected; a label can narrow a choice; a paragraph can reveal that the object was not yet understood.

Use [the prose method](references/source-grounded-expression.md) for argument, source meaning, examples and revision. Compose with the domain competence before writing a polished answer to the wrong question. Let an attempt at expression reveal a missing distinction, and return that knowledge to its owner.

Preserve exact operator wording when placement rather than rewriting is selected. Distinguish a source formulation, your interpretation and an observed result. Use the actual person, purpose and medium to choose depth and language; do not invent an audience reaction that changes what the source is allowed to mean.

An explanation can be the useful result without an action request. An instruction must identify the actual available action and consequence. A research direction, a candidate body, an installed resource and later use have different verbs. Precision belongs at the claim it changes, not in a repeated preamble seeking legitimacy.

Source language, stored working language and the current conversation language are different. Quoted text does not by itself select a language change. Preserve meaning across languages and formats without creating a second canonical product or theory.

When the draft reveals that a previous description hid a useful possibility, cooperate with [possibility formation](../maios-possibility-formation/SKILL.md) and [system understanding](../maios-system-understanding/SKILL.md). Return a reusable expression lesson here, domain knowledge to its domain and a formation lesson to the generative method. Drafting does not publish, send, alter a product or grant another source's authority.
