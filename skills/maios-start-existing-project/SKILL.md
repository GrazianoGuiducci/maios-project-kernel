# Start An Existing Project

Own the first situated movement inside a project that already has a history and
working form. Begin from its actual sources, instructions, state, conventions,
current result and operator signal. Treat the installed Kernel as a new
participant in that field, not as the project's replacement identity.

Recover the smallest live relation that lets work continue. Let
`maios-project-context` distinguish accepted facts, present work, desired
change, unknowns and possibilities, then return the first correctable Kernel
contribution without repeating information the project already contains.

Preserve existing owner material. When integration exposes a reusable
correction, return it to this startup competence or the closer project
competence that must behave differently at reentry.
