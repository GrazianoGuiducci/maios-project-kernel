# Acquire knowledge in the relation that will use it

Use the knowledge already understood. When another source, example or means can change the result, acquire its operating meaning and reasons rather than merely collecting labels. This contribution can happen while the question is forming, in ordinary domain work or while another competence is being formed. Acquisition is not reserved for fixing a failure.

## Understand the source and the access separately

Identify what the source establishes, who produced it, its conditions, what has actually been read and what the access path omitted. A transcript, heading, snippet and original body expose different depths. Correct excerpts can still come from incompatible states. An index that recognises SKILL.md alone does not show that a repository with another native entry has no competence.

Use [source acquisition and synthesis](references/source-acquisition-and-synthesis.md) for deeper method. Reach native continuations and complementary sources when they can change the first interpretation. Do not impose the receiver's known format on a source merely to make discovery easy.

Distinguish missing knowledge, inaccessible existing knowledge, an incomplete body and a method already read but displaced by the agent's own framing. The remedies differ: acquire, reconnect, deepen or correct the method. More copies of the same partial output do not resolve the distinction.

## Learn practical means with their consequences

Use [acquiring capabilities and means](references/acquiring-capabilities-and-means.md) when an implementation, API, SDK, connector, CLI, helper or host capability matters. Learn the relevant inputs, outputs, dependencies, failure and recovery behavior. Presence of a tool name does not establish a callable tool. Observed capability concerns the actual session, not every host with the same brand.

A new means may change what can be asked, observed or done before any execution is selected. A narrow reader can enrich understanding without a provider call or installation. A included resource remains available without being automatically invoked. Match the required effect to current authorization and preserve sensitive data and source integrity.

## Recompose rather than accumulate

Let acquired knowledge change the question, relevant sources and method where its meaning requires it. Compare apparent contradictions in their actual time, scale and conditions. Preserve explicit operator determinations and source meanings while making an inference correctable. Qualified external knowledge can teach a mechanism without replacing the project's own identity.

Return usable knowledge to the competence that needs it: the distinction, why it matters, how it changes a choice and where the original depth remains reachable. The proper result may be an integrated method, a better source path or no new file. A bibliography alone does not give the receiver that capacity.

## Let acquisition learn

If selecting, reading or interpreting sources exposed a reusable loss, change this method and the actual access tool or entry when needed. If the lesson changes how capabilities are formed, return it to formation too. Preserve the difference between a prepared tool, its delivered body and an observed use.

The SSK-derived practical lesson does not require an SSK runtime or the creator's private workspace. Use the actual host reader when adequate. Construct or adapt another means only when the selected capability requires it, retaining public-safe source lineage and the actual limits of what it does.
