## Missing relation closed

The earlier candidate could install, configure, compose represented faculties,
and maintain reviewed competence and host evidence. It did not yet own the
terminal causal relation from an actual resultant back to canonical project
continuity.

The implemented relation is:

```text
project configuration + host observations + competence state + open faculty field
-> derived autological operating context and causal freshness
-> situated movement and candidate resultant
-> pre-projection readback + actual result + possibility impact
-> independent accepted review
-> project-local admission into configuration, evolution, projections, and reentry
```

## Architecture selected

`src/maios_project_kernel/operating.py` is a deep value/result module. It was
selected over a stateful central `OperatingKernel` object because semantic
selection, review, owner authority, and future forms must not collapse into the
current class design.

The stable runtime seam is:

```text
operating-status [--circumstance]
validate-resultant --readback
admit-resultant --readback --expected-context-sha256
```

The module owns deterministic causal bookkeeping, invalidation, reviewed-event
shape, concurrency, local transition, projections, recovery, and receipts. It
does not own semantic truth, self-approval, improvement promotion, host
activation, or external effects.

## State and evolution

- `setup/CONFIGURATION_STATE.json` remains the project-configuration owner.
- `.maios/state/OPERATING_STATE.json` owns admitted terminal-result history and
  owner-governed assessment references.
- `.maios/context/OPERATING_CONTEXT.json` is derived and invalidatable, never a
  source owner.
- a terminal admission updates `current_next`, selected composition, possibility
  impact, crystallization, readable projections, and reentry coherently;
- self-improvement records `improve | verify_first | defer | no_change | reject`
  for an explicit target owner but never promotes it automatically;
- skills, competences, meta-skills, meta-competences, routers, and their present
  forms remain revisable or replaceable when a later relation changes.
