# Security policy

## Supported version

Security corrections currently target the latest published release.

## Reporting a vulnerability

Do not publish credentials, personal data, private project content, or an
exploitable report in a public issue. Use the private contact channel available
through [MAIOS](https://maios.it/) and include only the minimum information
needed to reproduce the problem.

The unconfigured package does not install services or activate external
integrations by itself. Host behavior and third-party tools retain their own
security and permission boundaries.
